## 📊 Data projects

| Project | Question | Key result |
|---|---|---|
| [Job postings forecast](https://github.com/Hadil16/job-postings-forecast) | Where will job postings go next? | 17 models backtested; a simple damped trend wins: 3.3% error at 13 weeks vs 5.4% for the naive baseline |
| [Telco churn](https://github.com/Hadil16/telco-churn-analysis) | Who is about to leave, and who should we call first? | 7,043 customers, AUC 0.845 |
| [Customer segmentation (RFM)](https://github.com/Hadil16/customer-segmentation-rfm) | Which customers matter most? | 22% of customers bring 68% of revenue |
| [Energy transition](https://github.com/Hadil16/energy-transition-analysis) | How fast is the world moving to renewables, and where is Algeria? | World renewables 19% → 30% of electricity (1990–2023); Algeria still 98.7% gas |
| [Olist e-commerce](https://github.com/Hadil16/olist-ecommerce-analysis) | What drives sales and delivery in Brazilian e-commerce? | 99K orders, SQL + Power BI |
| [Superstore profit](https://github.com/Hadil16/superstore-profit-analysis) | Why do some sales lose money? | Discounts above 20% destroy profit |

Each repository has a README with the question, the method, the result and the limits of the analysis.
